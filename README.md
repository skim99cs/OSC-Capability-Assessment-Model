# Python-based Project Management Assessment & Visualization Model

This repository contains the source code and research documentation for an automated capability and risk assessment program developed using **Python (Matplotlib)**.

## Project Overview
* **Objective:** Quantify and visualize organizational management capabilities across 8 core project domains based on PMI/CMAA international standards.
* **Key Features:** Automated data processing, ratio calculation against survey-weighted importance (derived via SPSS), and real-time 8-domain radar chart visualization.
* **Tech Stack:** Python 3.x, Matplotlib, NumPy, Google Colab / PyCharm

## Abstract
The purpose of this study is to develop a capability assessment model for Off-Site Construction (OSC) project management that objectifies the competency levels of OSC companies by evaluating essential management metrics. Given that most OSC processes occur in off-site facilities, this model focuses specifically on the manufacturing phase. Based on the 8 project management domains defined by PMI and CMAA, 21 key management items specific to the manufacturing process were derived. To establish the weighted importance of these items, a survey was conducted with 46 OSC industry experts, and dataset reliability was verified using SPSS. An automated model was then implemented using Python to calculate performance-to-importance ratios based on user inputs. The evaluated results are dynamic-visualized in an 8-axis radar chart, allowing companies to easily identify operational capabilities and risk areas. This model provides a practical framework for OSC firms to evaluate management efficiency, systematically identify performance gaps, and strengthen overall operational competitiveness.
